# 声纹工坊 · VoiceClone Studio

> 由 B 站 **@我是学编程的周二** 开发 · 代码以 MIT 许可开源

一个**本地离线运行**的音色克隆工作台：导入几段真人录音，软件自动清洗、挑出最佳片段，
建立可复用的「音色档案」，然后就能用这个音色朗读任意中文 / 英文 / 中英混排文本。

图形界面基于 PySide6（原生桌面窗口，不是网页），语音引擎可插拔，
默认接入 **F5-TTS**（零样本克隆，中英双语），并内置一个免模型的「系统语音」引擎，
用来在没有下载任何模型的情况下立刻跑通全流程。

---

## 一、它能做什么

**音色库**
- 一次导入多个音频文件，或直接拖一个文件夹进来（wav / mp3 / flac / ogg / m4a / aac / wma）
- 自动评估每条素材：时长、采样率、峰值、信噪比、削波比例、静音比例，给出 0~100 分与问题提示
- 自动挑选最适合做参考的一段（默认 4~12 秒），裁剪首尾静音、去直流、响度归一、可选谱减降噪
- 参考文本：可手动填写，也可用 faster-whisper 自动识别（可选组件）
- 音色可命名、可试听、可编辑、可删除，全部存在本地 `voices/` 目录

**语音合成**
- 选择音色 + 引擎，输入文本即可生成，实时进度、可中途停止
- 长文本按句自动切分为多段，逐段推理后带淡入淡出拼接，避免爆音
- 可调：语速、推理步数（NFE）、相似度 CFG、段落间隔
- 内置波形播放器：显示波形、点击波形跳转、导出 MP3（依赖内置 ffmpeg）

**批量合成**
- 每行一条文本，或导入 txt / csv，一次生成整套音频，按序号命名
- 表格实时显示每条的状态、时长与文件名

**文本兼容性（重点）**
所有文本都会经过一层规范化，再交给引擎：
| 输入 | 处理结果 |
|---|---|
| `Ｔｅｓｔ　全角ＡＢＣ` | `Test 全角 ABC` |
| `订单 2026-11-09 已发货` | `订单二零二六年十一月九日已发货` |
| `会议 9:30 开始` | `会议九点三十分开始` |
| `增长 12.5%` | `增长百分之十二点五` |
| `合计 ¥1280.50` | `合计一千二百八十点五零元` |
| `温度 18℃` | `温度十八摄氏度` |
| `5×6=30` | `五乘六等于三十` |
| `太棒了🎉👍` | `太棒了`（表情符号剔除） |
| `Python3.13` / `F5-TTS` | `Python 三点一三` / `F 五-TTS` |
| `2-3 小时` | `二到三小时` |
| `13800138000` | `一三八零零一三八零零零`（长数字串逐位） |
| 零宽字符、控制符、全角空格 | 全部清理 |
| 中英混排 | 自动在汉字与拉丁字母之间补空格，利于断句 |

任何字符都会经过覆盖度检查，无法朗读的字符会在「检查文本」里列出来。

## 二、快速开始

### 1. 启动
双击 **`启动.bat`**。首次运行会自动创建 `.venv` 并安装基础依赖（约 200MB，用官方源可能较慢，
建议先执行一次：`.venv\Scripts\python.exe -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`）。

想看日志就用 **`调试启动.bat`**。

### 2. 建立第一个音色
1. 进入「音色库」→ 点 **＋ 新建音色（导入素材）**
2. 添加若干条 5~15 秒的清晰人声（没有素材？用手机录一段，安静环境下念 2~3 句话）
3. 点 **开始分析与预处理**，等进度条走完，看右侧质量评分与波形
4. 在「参考文本」里输入这段音频**实际说的话**（可点「自动识别」）
5. 填音色名称 → **创建音色**

### 3. 安装克隆引擎（只需一次）
进入「设置」→ 找到 **F5-TTS · 零样本克隆** → 点「安装依赖」，
安装窗口会实时显示 pip 日志（会拉取 PyTorch，约 2GB）。

或者命令行：

```bat
.venv\Scripts\python.exe -m pip install -U f5-tts -i https://pypi.tuna.tsinghua.edu.cn/simple
```

模型权重（约 1.4GB）在**第一次合成时自动下载**到 `cache/hf/`；
国内网络默认走 `hf-mirror.com` 镜像（设置页可改）。

### 4. 合成
回到「语音合成」→ 选音色、选引擎 → 输入文本（点「填入示例」可试一段中英混排）→ **开始合成**。

> 想先验证流程而不下载模型？引擎选「系统语音 · 免模型」，它会调用 Windows 自带语音合成，
> 不克隆音色，但能完整走通文本处理、切句、拼接、导出。

## 二·五、多语言引擎（可选扩展包）

内置的 F5-TTS 只支持**中文和英文**。需要日语、韩语、粤语时，额外装
**「多语言扩展包」**（GPT-SoVITS，约 2.7 GB 压缩包 / 3.6 GB 解压）：

1. 把扩展包里的 `gpt_sovits` 文件夹解压到程序的 `resources` 目录
   （最终结构：`resources\gpt_sovits\python\python.exe`）
2. 重启程序，引擎下拉里会出现「GPT-SoVITS · 多语言克隆」

| | F5-TTS（内置） | GPT-SoVITS（扩展包） |
|---|---|---|
| 语言 | 中·英 | **中·英·日·韩·粤** |
| 模型体积 | 1.4 GB | 249 MB |
| 许可 | 权重 CC-BY-NC（不可商用） | **MIT（可商用）** |

它跑在一套独立的 Python 3.10 里（扩展包自带），和主程序互不干扰：装了才可用，
不装也不影响 F5。首次合成会启动本地服务并加载模型，约 30~90 秒；之后常驻，每段只需十几秒。

> 为什么单独放？GPT-SoVITS 的依赖（pyopenjtalk、funasr、pytorch-lightning）只支持
> Python 3.9~3.10，而主程序跑在 3.13 上，硬装进去会互相打架。

## 三、硬件与速度预期（含本机实测）

F5-TTS 是非自回归扩散模型，CPU 也能跑，但**非常吃算力**。本机（Xeon E3-1220 v2 / 4 核 4 线程 /
无独显）实测数据：

| 场景 | 产出音频 | 耗时 |
|---|---|---|
| NFE = 24，33 字中英混排 | 7.5 秒 | **650 秒**（约 11 分钟） |
| NFE = 8，15 字中英混排 | 4.0 秒 | **159 秒**（约 2.6 分钟） |

（同一条参考音频，同一台机器，仅改推理步数——相差 4 倍多。）

由此得到的建议：

- **纯 CPU 把推理步数调到 8~12**（界面默认已设为 10），这是速度/质量最划算的区间
- 一次合成尽量控制在 1~2 句；长文请用「批量合成」，让它慢慢跑
- 想真正流畅使用，建议 NVIDIA 显卡（8GB 显存以上，装 CUDA 版 PyTorch 后同句约 1~3 秒）
- 内存建议 8GB 以上（加载模型后常驻约 2GB），磁盘预留 6GB
- 显存不够或没有独显时，「设置 → 设备」保持 `cpu` 即可

> CPU 推理期间界面会显示「已用时 N 秒」，属正常现象，不是卡死；随时可点「停止」中断。

自检：

```bat
.venv\Scripts\python.exe tools\selftest.py
```

## 五、参数说明

| 参数 | 默认 | 作用 |
|---|---|---|
| 语速 | 1.0× | 0.5~1.8，超过 1.3 容易失真 |
| 推理步数 NFE | 24 | 越大越稳越慢，建议 16~32 |
| 相似度 CFG | 2.0 | 越高越像参考音色，>3 容易出现金属音 |
| 段落间隔 | 180ms | 长文本分段之间的停顿 |
| 单段最大字符 | 110 | 太大占内存，太小韵律变碎 |
| 目标响度 RMS | 0.12 | 输出整体音量 |

## 六、常见问题

**Q：卡在「正在加载 F5-TTS」很久？**
首次运行要下载 1.4GB 权重，看 `cache/hf/` 是否在增长。程序默认走 `hf-mirror.com` 并不会启用
Xet 传输协议（该镜像不支持 Xet，开着会慢十倍以上）。若仍然很慢，可在设置页换镜像，
或手动把 `model_1250000.safetensors` 放进 `cache/hf/`。

**Q：报 torchcodec / FFmpeg 相关的错误？**
程序已内置兼容层：绕开 torchcodec，改用 soundfile 解码参考音频，无需自己装系统 FFmpeg。
如果你手动改动过环境导致失效，重装 `soundfile` 即可。

**Q：合成一句要等好几分钟？**
这是纯 CPU 跑扩散模型的正常速度，把「推理步数」降到 8~10 会快 2~3 倍；有独显时换 CUDA 版 PyTorch 可提速数十倍。

**Q：合成出来不像 / 读错字？**
九成是参考文本和音频对不上。参考文本必须是那段音频里**逐字对应**的内容，
标点可有可无，但不能多字少字。换一段更干净、情绪平稳的素材也会明显变好。

**Q：中文被读成英文腔 / 英文被读成拼音？**
F5-TTS 是双语联合训练的，中英混读是它的强项；如果仍然不对，把文本按语言拆成两句分别合成，
或在「检查文本」里确认规范化结果是否符合预期。

**Q：系统语音引擎没声音？**
Windows 需要中文语音包：设置 → 时间和语言 → 语音 → 添加中文语音。

**Q：m4a / mp4 里的音频读不了？**
程序会自动调用 `imageio-ffmpeg` 自带的 ffmpeg 转码；如果仍失败，先用格式工厂之类转成 wav。

**Q：能商用吗？**
F5-TTS 模型权重遵循其自身许可（CC-BY-NC），**不可商用**。商用请替换为有商用授权的模型，
本项目的引擎层是插件式的，新增一个 `engines/xxx.py` 即可接入。

## 七、使用边界

音色克隆很容易被滥用。请确保：

- 你拥有所使用音频的合法授权（自己的声音、或已获得明确许可的声音）
- 不用于伪造他人身份、电信诈骗、虚假新闻、侵犯肖像权与声音权
- 对外发布合成音频时，主动标注「AI 合成」

软件不做任何联网上传，所有音频与模型都在本机处理。

## 八、打包成 exe（发行用）

源码运行是双击 `启动.bat`；**发行给别人**则打包成便携版，产物是
**几十 KB 的 exe + 一个 `resources` 资源目录**，目标机器不需要装 Python：

```bat
:: 轻量版（不含模型，用户首次合成时自动下载 1.4GB）
.venv\Scripts\python.exe tools\build_release.py --out E:\VCS-Release --no-models

:: 完整版（把已下载的模型一起打进去，离线可用）
.venv\Scripts\python.exe tools\build_release.py --out E:\VCS-Release --with-models
```

```
声纹工坊-v1.0.0/                 3.6 GB
├─ 声纹工坊.exe                  36 KB   ← 纯 Win32 启动器（MinGW 编译，无 Python）
├─ 使用说明.txt / VERSION.txt
└─ resources/                    3.6 GB
   ├─ app/                       170 KB  程序代码
   ├─ runtime/                   2.2 GB  独立 Python 3.13 + PySide6 + torch + F5-TTS
   ├─ bin/ffmpeg.exe             101 MB
   ├─ models/                    1.3 GB  F5-TTS 权重（完整版才有）
   └─ data/                      用户数据：voices / output / cache / logs
```

exe 只做四件事：定位 `resources\runtime\python.exe` → 设置
`VCS_HOME / VCS_MODELS / HF_ENDPOINT / PYTHONNOUSERSITE` 等环境变量 →
`CreateProcessW` 拉起 `resources\app\main.py` → 退出。
缺文件、启动即崩、3 秒内退出等情况都会弹中文提示并指向日志，
不会像 PyInstaller 打包那样出现"双击没反应"。

构建是**增量**的：重复执行只会补差异文件，改了代码重打包约 30 秒。
详细的分发建议、体积取舍、合规注意事项见 **`RELEASE.md`**。

> ⚠ F5-TTS 权重是 CC-BY-NC 许可：**打包分发可以，商业售卖不行**。
> 商用请按 `app/core/engines/` 的接口替换成有商用授权的引擎。
