安装步骤

下载后一路下一步，第一次打开会多等一会儿。

运行安装包

双击 声纹工坊-v1.0.2-安装包.exe，选择安装位置。默认装在当前用户目录，不需要管理员权限。

首次启动等下载

第一次打开会提示需要补运行环境（约 2.3 GB）。点「是」，等它自己下完解压，中途可以离开，断了会续传。

开始使用

补齐后自动进入主界面。以后再打开就直接启动，不联网也能用。

本次更新（v1.0.2）

这一版主要修首次安装的几个毛病，建议之前装过 v1.0.0 / v1.0.1 的都更新。

修好了「下完就没了」

旧版启动器把分卷解压到了 resources\resources\ 这个错误位置，导致程序找不到运行环境：下载完窗口一关就没了，下次打开又重新下一遍。现在解压到正确位置，并写入就绪标记。

桌面快捷方式能创建了

之前安装脚本调用的 make-shortcuts.ps1 根本没打进安装包，所以勾了「创建桌面快捷方式」也没反应。已补上。

启动失败会说明原因

运行环境不完整时不再静默退出，会弹窗告诉你缺哪个文件，而不是让你对着空桌面发呆。

自动清理旧版垃圾

新启动器会顺手删掉旧版本错误解压留下的 resources\resources\ 目录，那里可能白占了 3 GB 以上。

常见问题

下载中途断了

浏览器和程序都支持断点续传，重新点一次会接着下，不用从头来。

提示缺少 VCRUNTIME140.dll

系统缺少 VC++ 运行库。装一下 vc_redist.x64.exe 再启动即可。

杀毒软件报毒

PyInstaller 打包的程序常被误报。这是误报，可加白名单；源码全部开源，可以自己审。

没有 N 卡能用吗

能，会回退到 CPU 推理。速度慢很多，一条十秒音频大概两三分钟。
